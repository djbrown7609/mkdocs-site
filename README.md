# Documentation Site (MkDocs + Material)

This repository contains a technical documentation site built with MkDocs and the Material for MkDocs theme. The site showcases structured, developer-focused documentation with clean navigation, reusable components, and modern styling.

## Features

- Clean, responsive documentation site using Material for MkDocs
- Organized navigation with topic-based structure
- Markdown-based authoring for fast iteration
- Built-in search, code highlighting, and tabbed content
- Easy local preview with live reload
- Automated deployment to GitHub Pages
