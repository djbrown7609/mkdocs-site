# Amazon ECS API Reference

This reference provides an overview of the Amazon ECS API operations, including request structure, required parameters, response format, and common error conditions. You use this guide when you integrate Amazon ECS operations into your automation, tooling and deployment workflows.
One important aspect of this guide is to have clear and working examples.

---

## Overview

The Amazon Elastic Container Service (ECS) API enables programmatic control of containerized workloads. This includes creating and managing clusters, services, tasks, and related infrastructure components.

This reference outlines:

- Required and optional request parameters  
- Example request and response structures  
- Authentication and IAM considerations  
- Common error messages and troubleshooting guidance  

---


Documentation structure:

- Pages for each API operation and data type
- Guide is structured to display available actions for each resource
- Request syntax with validated JSON structures
- Constraints including what parameters must be used together in certain scenarios
- Defaults
- Errors users might encounter with guidance

Why this is important:

- Prevents user trial and error
- Reduces calls to support
- Presents use case examples
