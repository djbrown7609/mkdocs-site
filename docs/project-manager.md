## Tools I Have Used

I have hands-on experience with a wide range of Agile and project management tools that support planning, tracking, communication, and delivery.

### Jira
I used Jira to manage sprints, track user stories, coordinate with engineering teams, and maintain visibility into development progress. I created dashboards, monitored burndown charts, and ensured backlog items were properly groomed and prioritized.

### Monday.com
I used Monday.com to coordinate cross-functional projects, manage timelines, and track deliverables across multiple stakeholders. I built automated workflows, created project boards, and used dashboards to communicate status, risks, and dependencies.

### Asana
I used Asana to organize project tasks, manage dependencies, and keep distributed teams aligned on deadlines. I leveraged timeline views, task templates, and workload features to maintain clarity and ensure smooth execution.

### Confluence
I used Confluence to document requirements, create project plans, and maintain centralized knowledge bases. I collaborated with engineering and product teams to ensure documentation stayed current, accurate, and aligned with project objectives.

### Slack
I used Slack to coordinate daily communication, share updates, and integrate notifications from Jira, GitHub, and other project tools. It helped maintain fast, transparent communication across teams.

### GitHub Projects
I used GitHub Projects to track engineering tasks, manage issues, and align development work with project timelines. I coordinated closely with developers using boards, milestones, and automated workflows.
